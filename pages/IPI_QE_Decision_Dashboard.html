How to use this dashboard

  1. Use Overview to identify the department and cost category that matter most.
  2. Open a Pareto bar or Part explorer row to inspect monthly quantity, amount and ratios for the same PN.
  3. Use Month comparison to distinguish repeat-PN changes from production mix changes.
  4. Create an action with an owner, due date, metric and target. Record the root cause and corrective action after investigation.
  5. Enter a post-action result and evidence before closing. Report history is not rewritten by manual verification.

Definitions

Failure cost rateTotal failure cost / production value × 100%
Preparation cost rateTotal preparation cost / production value × 100%
Production valueSum of production quantity × unit price
Scrap quantity rateTotal scrap quantity / production quantity × 100%
Combined selected costFailure + preparation. Sorting and separately recorded QC sample costs are not added.
Cost change: repeat PN volume effect(Current qty − baseline qty) × baseline loss cost per produced piece
Cost change: repeat PN rate / valuation effectCurrent qty × (current loss cost per piece − baseline loss cost per piece)

Cost-rate targets belong to the department; they are reference values, not PN acceptance limits. No-production months are missing observations, not 0% quality. M/C, I/S and S/S use the source's categories; they do not establish defect root causes. All displayed monetary amounts are SGD (S$).

Action status and verification are entered by users. There is no live database, multi-user synchronization or Excel upload in this version. Use Export backup before clearing browser data or moving the file. Print / PDF exports the current section; export CSV provides the full filtered detail.
